# Яндекс Диск

Плагин подключает Яндекс Диск к каталогу файлов: папка **@yadisk** в «Файлах», у `pulse files` и в смонтированном
дереве (`$PULSE_FS_DIR/@yadisk`). Внутри — **подключения**, каждое — своя папка:

- весь диск или папка аккаунта (`mount folder`) — чтение и запись; сюда же — **общие папки**, которые владельцу
  открыли и он принял приглашение (они лежат на его диске);
- публичная ссылка (`mount public`) — только чтение, вход не нужен.

```bash
pulse yadisk mounts                              # что подключено: имя → @yadisk/<имя>, откуда, только ли чтение
pulse yadisk accounts                            # аккаунты, место, не истёк ли вход
pulse files ls "@yadisk/Работа/Отчёты"           # дальше — обычные файлы
pulse files get "@yadisk/Работа/Отчёты/q3.pdf"   # скачать к себе для обработки
pulse yadisk publish --path "@yadisk/Работа/Отчёты/q3.pdf"   # публичная ссылка — дать её кому-то
```

## Правила

- **Сеть, а не диск.** Каждое обращение к @yadisk — запрос к Яндексу. Не обходи хранилище целиком (`grep -r`,
  `find` по всему @yadisk, `pulse files find` его не ищет): иди по папкам, которые назвал владелец. Для тяжёлой
  обработки скопируй нужные файлы к себе (`pulse files get`, `cp` из дерева) и работай с копией.
- **Запись — по просьбе.** Класть, переименовывать и удалять файлы на Диске владельца — только когда он просит;
  удаление уходит в корзину Диска, но всё равно спрашивай перед удалением папок. Результаты своей работы клади в
  свои папки Пульса, если владелец не сказал «положи на Диск».
- **Вход делает владелец.** Пароль и коды Яндекса не проси и не вводи. Нужен ещё аккаунт — `pulse yadisk login`
  и передай владельцу ссылку и код из ответа (поле tell_owner) либо отправь на страницу [Яндекс Диск](/p/yadisk/main);
  потом `pulse yadisk login status`.
- **Общая папка не видна** в `browse` — значит, владелец ещё не принял приглашение: попроси принять его в Яндекс
  Диске (письмо или раздел «Общий доступ»), затем `pulse yadisk mount folder --account … --path "/Имя папки"`.
- **Публичная ссылка** — `pulse yadisk mount public --url https://disk.yandex.ru/d/…`; менять файлы в ней нельзя —
  `pulse yadisk save --name <подключение>` сохранит копию в «Загрузки» аккаунта, её можно подключить и править.
- «Вход истёк» в ответе или сигнал «Войдите в Яндекс снова» — попроси владельца войти снова на странице плагина.
- Вход не начинается, Диск не отвечает — `pulse yadisk check`: покажет, где обрыв. «Вход: oauth.yandex.ru» не
  прошёл — серверу Пульса нужен прокси в РФ (INSTALL.md плагина, шаг 1а); адрес прокси с паролем — секрет, задаётся через stdin и не пишется в ответах.

# Установка плагина «Яндекс Диск»

Инструкция для агента Пульса после `pulse plugins install …`. Пройди её целиком.

## 1. Проверь, что плагин запустился

```bash
pulse plugins list            # у yadisk — status: running
pulse yadisk accounts         # app.configured: true — приложение Яндекс OAuth есть; accounts: [] до входа
```

Если status: error — `pulse plugins logs yadisk --lines 80`, расскажи владельцу, что в журнале, и остановись.
Нужен Пульс с контрактом плагинов 1.4 (папки-хранилища @<плагин>, проверка подключения).

## 1а. Проверь доступ к Яндексу — обязательно

```bash
pulse yadisk check            # по шагам: приложение OAuth, прокси, «Вход: oauth.yandex.ru», «Диск: cloud-api…», аккаунты
```

То же — кнопка «Проверить подключение» в Настройки → Плагины → Яндекс Диск.

- **«Вход: oauth.yandex.ru» не прошёл** («нет соединения» или «зависает TLS») — сервер Пульса, скорее всего, не в
  России, и Яндекс не пускает его ко входу. Нужен прокси в РФ. Спроси владельца, есть ли у него сервер или прокси в
  России (описание может лежать в его карточках или файлах — поищи: `pulse cards list --q прокси`,
  `pulse files find прокси`). Адрес прокси с логином и паролем — секрет: владелец задаёт его сам
  (`pulse plugins secret yadisk proxy`, формат `http://логин:пароль@хост:порт` или `socks5://хост:порт`). Прокси на
  своём сервере в РФ можно поднять (например, 3proxy или tinyproxy, доступ — только с адреса сервера Пульса и с
  паролем); не открывай прокси всему интернету.
- **«Диск: cloud-api.yandex.net» не прошёл** при работающем прокси — включи `pulse plugins settings yadisk set
  proxy_all=true`: тогда через прокси пойдут все запросы к Яндексу, не только вход.
- После смены настроек плагин перезапускается сам — повтори `pulse yadisk check`, пока все шаги не станут ok
  (кроме приложения OAuth и аккаунтов, если их ещё не задали).

## 2. Приложение Яндекс OAuth

Вход в аккаунты работает только с приложением Яндекс OAuth из настроек плагина — значений по умолчанию нет.
Если `app.configured: false`, спроси владельца, есть ли у него ClientID и Client secret: для доверенных установок их
выдаёт администратор Пульса. Есть — пусть задаст их сам (пункт 3 ниже). Нет — либо пусть запросит у администратора,
либо зарегистрирует своё приложение:

1. oauth.yandex.ru → «Создать приложение»; платформа — «Для доступа к API или отладки» (Redirect URI —
   https://oauth.yandex.ru/verification_code);
2. права: «Яндекс Диск REST API» — чтение всего Диска, запись в любом месте Диска, доступ к информации о Диске
   (cloud_api:disk.read, cloud_api:disk.write, cloud_api:disk.info);
3. ClientID и Client secret — в настройки плагина (Настройки → Плагины → Яндекс Диск) или командами:

```bash
pulse plugins settings yadisk set client_id=<ClientID>
pulse plugins secret yadisk client_secret         # секрет вводит владелец, не проси его в чат и не пиши сам
```

## 3. Закрепи страницу

```bash
pulse plugins pin yadisk main
```

## 4. Вход — делает владелец сам

Пароль Яндекса вводит только владелец, на сайте Яндекса, в своём браузере. Не проси у него пароль и коды. Либо
отправь владельца на страницу [Яндекс Диск](/p/yadisk/main) → «Войти в аккаунт Яндекса», либо:

```bash
pulse yadisk login            # user_code и verification_url — передай владельцу текст из tell_owner
pulse yadisk login status     # done — вход выполнен, весь диск аккаунта подключён папкой @yadisk/<имя>
```

Аккаунтов может быть несколько: каждый следующий вход — ещё один аккаунт.

## 5. Подключения (если владелец просит)

```bash
pulse yadisk browse --account <логин>                           # папки, в том числе принятые общие
pulse yadisk mount folder --account <логин> --path "/Проект Альфа"
pulse yadisk mount public --url https://disk.yandex.ru/d/…      # публичная ссылка, только чтение
pulse yadisk mounts
```

## 6. Проверь

```bash
pulse yadisk check            # все шаги ok
pulse files ls @yadisk        # подключения как папки
pulse files ls "@yadisk/<подключение>"
```

## 7. Расскажи владельцу

Что установлен «Яндекс Диск» (версия), страница закреплена в меню, Диск виден в «Файлах» папкой @yadisk и доступен
агентам; можно войти в несколько аккаунтов, подключить отдельные и общие папки и публичные ссылки. Вход продлевается
сам; если он истечёт — придёт сигнал «Войдите в Яндекс снова».
